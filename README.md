# 影阁 · PyVideo

把电脑上的 4K 视频，变成手机浏览器里的私人影院。

一个端口同时提供两种界面：电脑打开是管理端，手机打开是观看端。手机和电脑连接同一个 Wi-Fi 后扫码即看，不需要装 App、不需要上传视频。

## 功能

- **自动区分设备**：同一个地址，电脑进入管理界面，手机进入观看界面。
- **一个端口搞定**：默认 `8686`，启动后电脑自动打开管理页，手机扫码访问。
- **文件夹即影库**：填写或浏览选择视频文件夹，递归扫描子目录；支持多个文件夹。
- **直连优先**：兼容的 MP4/MOV 使用 HTTP Range 直连原画，秒开、可随意拖动。
- **MKV 快速转封装**：视频不重新编码，只把 MKV 封装成 HLS，几秒内起播。
- **兼容转码**：H.264 10bit、AV1、VP9 等浏览器不支持的编码，按需转成 H.264；自动尝试 NVENC / QSV / AMF 硬件加速，失败回退 CPU。
- **手机体验**：基于 ArtPlayer 的现代播放器，支持手势、倍速、画面比例、字幕偏移、画中画、全屏与 AirPlay；缩略图、搜索、文件夹筛选、继续观看、播放进度记忆、锁屏媒体信息、屏幕常亮、字幕与画质切换。
- **缓存与清理**：HLS 分片缓存自动清理，也可在管理端一键清空。
- **单文件 exe**：PyInstaller 打包，双击即可运行。

## 快速开始（使用打包好的 exe）

1. 双击 `PyVideo.exe`。
2. Windows 防火墙弹窗时，勾选“专用网络”并允许访问。**这一步必须允许，否则手机连不上。**
3. 电脑浏览器会自动打开 `http://127.0.0.1:8686/pc`。
4. 在“视频文件夹”里填写路径（例如 `D:\Movies`），或点“浏览…”选择文件夹，然后添加。
5. 等扫描完成。首次会分析编码并生成缩略图，4K 视频较多时需要一点时间。
6. 手机连接**同一个 Wi-Fi**，用相机扫描电脑页面上的二维码，或直接在手机 Chrome 输入 `http://电脑IP:8686`。
7. 如果页面提示未安装 FFmpeg，点“一键下载”；也可以按下方说明手动指定。

> 手机和电脑必须在同一个局域网；路由器开启了“AP 隔离 / 访客网络”时手机无法访问电脑，请关掉。

## 从源码运行

```bash
python -m pip install -r requirements.txt
python run.py
```

可选参数：

```bash
python run.py --port 9000      # 指定端口
python run.py --no-browser     # 不自动打开浏览器
```

FFmpeg 可以稍后在管理页面点“一键下载”，或手动放到以下任意位置：

- `%LOCALAPPDATA%\PyVideo\bin\ffmpeg.exe` 与 `ffprobe.exe`
- exe 同目录的 `bin\` 子目录，或 exe 同目录
- 系统的 PATH
- 在管理页“手动指定路径”中填写包含 `ffmpeg.exe` 的目录

## 打包成单个 exe

```bat
build.bat
```

输出：`dist\PyVideo.exe`。

- 默认**不包含** FFmpeg，exe 约 40 MB，首次在页面点一键下载（约 115 MB）即可。
- 如果想离线使用、彻底单文件：先下载 Windows 版 FFmpeg，把 `ffmpeg.exe` 和 `ffprobe.exe` 放进项目根目录的 `bin\`，再执行 `build.bat`。exe 会增大到一百多 MB，但启动后无需联网。
- 打包后的配置、缩略图、缓存都存放在 `%LOCALAPPDATA%\PyVideo`，与 exe 位置无关，重新打包不会丢失。

## 播放方式说明

服务会根据编码自动选择最省力的路径：

| 源文件情况 | 播放方式 | 起播速度 | 说明 |
| --- | --- | --- | --- |
| MP4/MOV，H.264 或 H.265（hvc1），AAC/MP3 音轨 | **直连** | 立即 | 原画、完整拖动、占用 CPU 低 |
| MKV/AVI，H.264/HEVC，AAC/其他音轨 | **快速转封装** | 几秒 | 视频直接复制，音轨不兼容时转 AAC |
| H.264 10bit、AV1、VP9、MPEG-2 等 | **转码** | 几秒到更久 | 转成 1080P/720P H.264；有 NVENC/QSV/AMF 时优先硬件编码 |
| HEVC MP4 但标记为 hev1 | **快速转封装** | 几秒 | 修正为 hvc1 后交给 iPhone 解码 |

画质选项：

- **自动**：直连优先；MKV 用原画转封装；不能复制时才转码。
- **原画**：保持分辨率。MKV 仅转封装；编码不受支持时按原分辨率转码（4K 软转较慢）。
- **1080P / 720P**：强制转码到对应高度，兼容性最好。

> 4K 原盘码率常见 40–100 Mbps。千兆路由器不代表手机能跑满千兆：请连接 5GHz Wi-Fi，并尽量靠近路由器。如果直连卡顿，切到 1080P 通常更流畅。
>
> HDR 视频建议优先使用直连或“原画转封装”以保留 HDR；强制转成 1080P/720P 时可能损失 HDR 色彩，画面会偏灰。

## 字幕

支持与视频同目录、同名的外挂字幕：

- `电影.mkv` + `电影.srt`
- `电影.mkv` + `电影.zh.srt` / `电影.chs.srt` / `电影.en.vtt`

自动识别 UTF-8 / GBK / Big5 编码，SRT 会转换为 WebVTT 后交给播放器。在播放器的齿轮设置里可以选择“关闭 / 中文 / English”等字幕；iPhone 进入系统全屏后，可在原生播放器的字幕（CC）菜单中开关。

暂不支持内嵌字幕轨（PGS/ASS 内封），有需要时建议使用外挂 SRT。

### 播放器操作

- 点击画面显示或隐藏控制栏，左上角是返回按钮。
- 右下角齿轮提供：画质、字幕、播放速度、画面比例、字幕偏移。
- 底部还有画中画、网页全屏、全屏；Safari 支持 AirPlay。
- 手机端支持手势快进、长按倍速、自动横屏等 ArtPlayer 内置交互。
- iPhone 进入全屏时会交给系统原生播放器，自定义控制栏会被系统控制栏替代，这是 iOS 的限制。

## 数据与缓存

数据目录：`%LOCALAPPDATA%\PyVideo`

```
settings.json     端口、文件夹、默认画质
progress.json     观看进度
media_cache.json  视频编码信息缓存（按文件修改时间失效）
thumbs/           缩略图
hls/              按需转码产生的 HLS 分片缓存
bin/              一键下载的 FFmpeg
```

- HLS 缓存会在闲置 30 分钟后自动清理，最多保留 6 个转码会话；缓存总量超过 30 GB 时会优先清理闲置会话，也可以在管理页手动清理。
- 转封装会临时占用与视频大小相近的磁盘空间，这是正常的。
- 删除/移除文件夹只影响影库，不会删除硬盘上的视频。

## 常见问题

**更新程序后手机页面样式错乱，播放器只在左上角**

- 通常是手机浏览器缓存了旧的 CSS/JS。v1.1.1 已给静态资源加版本号并禁用强缓存；请关闭标签页后重新打开 `http://电脑IP:8686`，或在 Chrome 设置中清除该站点的数据。
- 确认没有开启 Chrome 的“请求桌面网站/桌面版网站”，手机端地址应为 `http://电脑IP:8686/watch`（二维码就是该地址）。
- 竖屏播放横屏电影时，视频会按比例居中，上下出现黑边是正常现象；点播放器右下角全屏或把手机横过来即可铺满屏幕。

**手机打不开页面**

- 确认手机和电脑在同一个 Wi-Fi，且不是访客网络。
- 检查 Windows 防火墙是否允许了该程序（专用网络）。第一次运行最好点“允许访问”。
- 管理页顶部显示的地址就是手机应该访问的地址，例如 `http://192.168.1.7:8686`。
- 如果电脑装了 VMware/VirtualBox 等虚拟网卡，手机地址可能显示成虚拟网段；以电脑默认上网网卡的 `192.168.x.x` 为准。
- 部分路由器开启了 AP 隔离/客户端隔离，需要在路由器里关闭。
- iPhone（iOS 18 及以上）首次访问局域网地址时，系统会询问“本地网络”权限，请选择允许；如果误点了拒绝，可在 设置 → Chrome/Safari → 本地网络 中重新打开。

**页面提示“未安装 FFmpeg”或 MKV 无法播放**

- 在管理页“转码引擎”点“一键下载”，完成后程序会自动重新分析影库。已安装 FFmpeg 时也可以点“更新”重新下载最新版（例如需要更好的 NVENC 硬件加速）。
- 下载慢的话，可以自行下载 Windows 版 FFmpeg，把 `ffmpeg.exe`、`ffprobe.exe` 放到 `%LOCALAPPDATA%\PyVideo\bin`，再点“应用”。

**iPhone Chrome 播放 H.265 失败**

- iOS 的 Chrome 使用系统 WebKit，通常支持 H.265 硬件解码；若仍失败，在播放页右上角把画质切成“1080P”走 H.264 转码。
- 仍不行时可以换 Safari 打开同一地址。

**拖动进度条后要等很久 / 一直转圈**

- 正在转码的视频只能播放已经生成的分片。向后拖动到尚未转码的位置需要等待；直连和原画转封装的视频没有这个问题。
- 想快速随意拖动，优先选择“原画”或使用兼容的 MP4 源。

**4K 播放卡顿**

- 先确认手机连的是 5GHz Wi-Fi；2.4GHz 通常跑不满 4K 原盘。
- 直连卡顿时切 1080P；反之如果 CPU 较弱，优先让视频直连或原画转封装。
- 转码时可以看管理页显示的是硬件编码还是 CPU x264；NVIDIA/Intel/AMD 显卡通常能大幅提速。

**端口被占用**

- 程序会自动尝试 `8686` 之后的端口，并在启动横幅里显示实际端口。
- 也可以在管理页“服务设置”里修改端口，重启程序后生效。

**关闭手机屏幕后播放停止**

- 网页会尝试申请屏幕常亮；iOS 锁屏仍可能暂停播放。进度会保存，解锁后从上次位置继续。

## 安全说明

本项目面向**家庭局域网**，没有账号密码体系：局域网内能访问端口的人就可以管理影库、播放视频。请不要在路由器上做端口映射/内网穿透把服务暴露到公网。

## 项目结构

```
app/
  main.py          FastAPI 应用、路由分发、启动逻辑
  api.py           管理/播放 API
  media.py         扫描、探测、兼容性判断、缩略图、字幕
  streaming.py     Range 直连、HLS 会话、清理
  ffmpeg_tools.py  FFmpeg 定位/下载、硬件编码探测
  network.py       局域网地址、二维码
  config.py        配置与进度持久化
web/
  index.html       单页应用入口
  css/app.css      管理端 + 手机端样式
  js/common.js     工具与 API
  js/pc.js         电脑管理界面
  js/watch.js      手机观看界面 + 播放器
  vendor/artplayer.js  ArtPlayer 播放器（MIT）
  vendor/hls.min.js   桌面端 HLS 回退
run.py             启动入口
py-video.spec      PyInstaller 配置
build.bat          一键打包
```

技术栈：Python 3.10+、FastAPI、Uvicorn、原生 JS/CSS、ArtPlayer（MIT）、HLS.js（Apache-2.0，仅桌面回退）、FFmpeg（按需）。
